# 色当てクイズ (Color Quiz)

画面に表示されたRGB値の色を見て、正しい色名を選択肢から選ぶクイズアプリです。
HTML / CSS / JavaScriptのみで構成された静的サイトで、GitHub Pagesにて公開しています。

## デモ

[こちらから遊べます](https://sakamoto-08.github.io/color-quiz/)

## 機能

- ランダムな色（RGB値）をカラーパネルに表示
- 4択の選択肢（色名）からクイズ形式で回答
- 正解・不正解を判定し、リアルタイムでフィードバックを表示
- 全問終了後、正答数（スコア）を表示
- 「もう一度挑戦する」ボタンでリスタート可能

## 使用技術

- HTML5
- CSS3（Flexbox / レスポンシブ対応）
- JavaScript（Vanilla JS）

## 工夫した点

- **データ構造とロジックの可読性**: 色データと選択肢をオブジェクト配列で一元管理し、ランダム抽選ロジックをシンプルかつメンテナンスしやすく設計しました。
- **UI/UXと視覚的フィードバック**: 正解・不正解時にパネルの色やメッセージを即座に変化させ、ユーザーが直感的に結果を把握できるよう配慮しました。
- **レスポンシブデザイン**: スマートフォン閲覧時にも選択肢が押しやすいよう、ブレイクポイントを設定して1列レイアウトへ自動調整される設計にしました。
