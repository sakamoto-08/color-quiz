# 色当てクイズ (Color Quiz)

画面のカラーパネルに表示された色を見て、正しい色名を4択から選ぶクイズアプリです。
HTML / CSS / JavaScript のみで構成された静的サイトで、GitHub Pages にて公開しています。

## デモ

[こちらから遊べます](https://sakamoto-08.github.io/color-quiz/)

## 遊び方

1. カラーパネルに表示された色を見る
2. 4つの色名から正解を選ぶ
3. 正解・不正解のフィードバックを確認する（1.5秒後に次の問題へ）
4. 全10問終了後、正答数を確認する
5. 「もう一度挑戦する」で、出題順を入れ替えて再開できる

## 機能

- 13色のデータから、1ラウンド10問を重複なしで出題
- カラーパネルに色を表示し、4択（色名）から回答
- 正解・不正解を判定し、枠色とメッセージでフィードバックを表示
- 全問終了後、正答数（スコア）を表示
- 「もう一度挑戦する」ボタンでリスタート可能

## 工夫した点

- **データ構造とロジックの可読性**: 色データ（日本語名・英語名・RGB値）をオブジェクト配列で一元管理しました。開始時に Fisher–Yates でシャッフルし、先頭10色を出題することで、同じラウンド内の重複を防いでいます。
- **UI/UXと視覚的フィードバック**: 正解・不正解時にパネルの枠色とメッセージを即座に変化させ、ユーザーが直感的に結果を把握できるよう配慮しました。
- **レスポンシブデザイン**: スマートフォン閲覧時にも選択肢が押しやすいよう、ブレイクポイントを設定して1列レイアウトへ自動調整される設計にしました。
